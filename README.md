# Letter Rush (web)

The browser version of Letter Rush. Open `index.html`, or scan a challenge QR code from the app.

- Hebrew word list (`he_dict.js`): Hspell word lists (c) Nadav Har'El and Dan Kenigsberg, via
  github.com/eyaler/hebrew_wordlists, licensed GNU AGPL-3.0.
- QR codes: qrcode-generator (c) Kazuhiko Arase, MIT license.
- Online play uses Supabase with the public (publishable) key only; all game rules run on the server.
